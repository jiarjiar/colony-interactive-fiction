# 《殖民地》互动式文游

菲利普·迪克短篇《殖民地》的数据驱动互动改编。玩家扮演劳伦斯·霍尔少校，在被判定“绝对安全”的蓝星基地中，从日常物品的微小误差追查。

## 直接游玩

用 Chrome、Edge、Firefox 或 Safari 打开 `直接试玩.html`，作品会自动载入并进入阅读；不需要再手动选择 JSON。桌面端采用左侧场景图、右侧多段正文的布局，窄屏会自动改为上下排列。

如果要把剧本载入通用播放器，也可以打开 `剧情游戏启动器.html`，点击“插入 JSON 剧本”，选择同目录下的 `殖民地.json`。

游戏包含六章、314 个节点、5 个正式结局、3 个草率结局和 12 项成就。主状态值为“误差”；前期观察会通过 flags 改变终局可见选项。阅读器会把同一页的段落集中显示，并在不改变选择、状态与结局条件的前提下合并纯“继续”回调，减少重复点击。

## 文件说明

- `直接试玩.html`：内嵌完整剧本、打开即玩的推荐入口；场景图仍从同目录的 `概念图/` 读取。
- `殖民地.json`：可直接导入通用启动器的剧本。
- `剧情游戏启动器.html`：无需服务器的通用单文件播放器。
- `生成殖民地.py`：从可审计的章节节拍生成完整 JSON 和直接试玩版。
- `审核殖民地.py`：执行带条件的状态遍历，验证结局和成就真实可达。
- `生成概念图.py`：读取 14 张 GPT Image 科幻概念图并重建总览页。
- `概念图/总览.html`：概念图画板；点击画面可打开原尺寸 JPG。
- `设计文档/`：原作索引、风格锚点、分支拓扑、状态矩阵和逐章设计。

## 重新生成与验证

在本目录运行：

```bash
python3 生成殖民地.py
python3 ../你一生的故事-交互式文游/story-to-game/scripts/validate.py 殖民地.json
python3 审核殖民地.py
python3 生成概念图.py
```

官方结构校验检查引用、死路、静态可达性和结局收束；`审核殖民地.py` 进一步按实际条件和 flags 遍历状态空间，避免“静态可达但游玩时永远进不去”的假阳性。

## 改编原则

- 恐怖发生在正常日光和精确的物理动作里，不依赖黑暗或怪物外形。
- 复制物只比原件更整齐、更均匀；砷化氢下的显形态是半透明乳白凝胶，不使用血液或器官意象。
- 真正的救援线依赖公平呈现的三类证据：约定时间、缺失的着陆声和标准通讯呼号。
- 正式结局均包含即时后果、数日后、一个月后、关键物件去向及独立结局判断。
