## 二、主干节拍与分支

### 第一章：无害行星

`ch1_lab_01` 建制：蓝星、霍尔身份、殖民评估 → 与弗兰德利谈“无害”结论 → 观察窗外自然 → ★态度分支：强调检测/保留一个样本复核（各自callback）→ 独处 → 显微镜袭击（强制动作链）→ ★路径分支：立刻叫人/先检查残骸 → 实验室复核，完整显微镜重现 → ★命运错误：接受“只是幻觉”并停止追查 → 草率结局R1；其余进入心理测试 → 测试判定不稳定 → 章末返回住舱。

关键回响：选择复核者在后续更早注意到“数量”；立刻叫人使弗兰德利态度稍好；先检查残骸获得材质线索但证词更孤立。

### 第二章：日用品

住舱假性平静 → 毛巾袭击 → ★动作分支：用水龙头缠住/撞门脱身 → 腰带活化 → 椅子阻截 → 冲到走廊 → ★路径分支：去指挥室/回实验室取残片 → 被莫里森拘押 → 押送途中经过泰勒办公室 → 地毯袭击泰勒 → ★动作分支：射击边缘/拖走泰勒（不同伤情与证据）→ 集体确认异常 → 指挥室第一次推演“复制无机物”。

关键回响：实验室残片路线获得`found_residue`；救泰勒方式影响`morrison_stance`和后续是否得到额外人员支持。

### 第三章：成双之物

多兹通讯中断 → 霍尔抵达现场，看到两双手套与录音尾声 → 两块消毒垫事件由入口监控和幸存者口述建立 → ★调查路径：检查成对物/检查消化残留 → 建立“原件与复制品会同时存在”的暂时规则 → 野外车辆失联 → 通过车载通讯听见第二台车靠近 → ★行动分支：远程警告/组织救援 → 湖边小队呼叫，盖尔进林穿衣后失踪 → 搜救现场只剩成堆衣物和断裂通讯器 → ★态度分支：宣布所有物件可疑/坚持先找共同物理反应 → 回到实验室准备毒剂测试。

草率结局R2入口：玩家坚持亲自穿戴现场手套验证，8–10节点完整死亡/失联线。

### 第四章：半间实验室

选择测试区 → 检查呼吸头盔 → ★路径分支：保留一罐砷化氢备用/全部接入喷雾器 → 封闭实验室 → 释放毒剂 → 等待 → 大量器材融解 → ★行动分支：记录显形顺序/优先救门边卫兵 → 在毒气中发现枪击会引爆 → ★命运错误：开枪阻止扑来的复制物 → 草率结局R3；正确路径关闭火源、撤出 → 走廊会议讨论焚毁星球、留守或撤离 → 与莫里森形成撤离协议。

关键回响：`kept_arsine_reserve`解锁毁船路线；记录顺序获得复制物“先模拟功能、后模拟磨损”的线索；救卫兵提升莫里森支持。

### 第五章：什么也不带

通讯室联络戴维斯 → 明确“约两小时，15:00到达” → ★观察分支：记下时刻/只复述撤离要求 → 讨论无机物不得登船 → 下令全员裸体集合 → 逐个放弃衣物、武器、纪念品 → ★态度分支：公开说明理由/只给命令 → 穿过基地 → 窗外飞船已停在降落场 → ★观察分支：看时钟/看人群反应 → ★观察分支：听环境/催促前进 → 走近船体 → ★观察分支：检查着陆痕迹/仰看舱门 → 船闸开启，内部黑暗寂静 → 终局决策门。

公平证据只通过当屏物理事实呈现：14:50；此前无着陆声；地面没有新压痕或热迹；没有戴维斯的标准应答；船闸内无引导灯和人员。

### 第六章：十五点

终局决策根据已见线索显示合理选项：

1. **跟随全员登船** → 原作线“比人更大的仿制品” → 全员消失 → 真戴维斯15:00抵达 → `ending_original`。
2. **拉住莫里森，要求再等十分钟** → 若证据不足，只有两人留下、其他人登船 → 假船消失 → 真船抵达 → `ending_partial`。
3. **以时间+静默+通讯验证说服全员后撤** → 建立远距口令，等到真船按时、有声着陆 → 裸体分批登舰、隔离 → `ending_rescue`。
4. **有备用砷化氢时，布置诱饵并点燃假船** → 霍尔或志愿者承担近距离引爆 → 大部分人获救但留下死亡/污染代价 → `ending_burn`。
5. **集齐全部证据且拒绝任何飞船时** → 所有人留在蓝星，要求戴维斯不着陆，地球将行星永久列为隔离区 → `ending_quarantine`（隐藏）。

## 三、分支文学大纲

### 主线：比人更大的仿制品（原作真结局）

霍尔尽管经历了所有复制物事件，仍把“救援舰”归入制度保证的安全对象。莫里森在舷梯前停住，他用撤离命令压过迟疑。队员一个接一个进入没有灯、没有引导员的船闸。舱内没有机械声，只有脚步被黑暗吸收。船体表面在最后一人进入后恢复平整。15:00，真正的戴维斯抵达，按约定等待；无人回应。结局线用戴维斯的职业程序、重复呼叫、派出观察镜和报告措辞收束，不展示船内猎奇画面。

- 独有场景：假船内部边缘、真巡航舰控制室。
- 关键选择：是否用“命令已下”压过莫里森的迟疑。
- 后果：全队失踪；地球只收到一份不完整报告；蓝星仍被误判。
- 预算：18–22节点。

### 分支线：留下两个人（部分获救）

霍尔无法证明飞船是假，但坚持让莫里森和自己留在地面复核时刻。莫里森允许其他人自行登舰，秩序因此分裂。多数队员把地面的迟疑当成霍尔又一次不稳定；弗兰德利最终进入舱门。假船带着他们无声消失。十分钟后真船伴随推进声抵达，霍尔与莫里森被救，但他们必须解释为何没有强行拦住其他人。一个月后，调查委员会把事故写成“认知判断失败”，两位幸存者长期隔离。霍尔保留那只没有走快十分钟的基地时钟。

- 独有互动：莫里森是否留下、队员投票、真船上的质询。
- 后果维度：同伴死亡、两人关系、军事调查、隔离生活、时钟归处。
- 预算：14–18节点。

### 分支线：按时抵达（全员获救）

霍尔把三个事实放在一起：不到15:00、没有着陆声、戴维斯没有通过通讯确认。莫里森不是因信任霍尔而下令，而是因证据足够。全员后撤到空旷地，假船的舱门继续等候，随后船体边缘开始下垂。真正的巡航舰按时伴随震动和尘土抵达，戴维斯保持距离，用约定口令逐项确认。幸存者裸体、分组、在无机装备零接触条件下进入隔离舱。一个月后地球暂停殖民，霍尔在听证会上拒绝把事件称为胜利：他们只是对一个时间差多看了十分钟。

- 独有互动：三段证据陈述、远距口令、登舰顺序。
- 后果：全员生还；长期隔离；殖民计划冻结；时钟成为证物。
- 预算：18–24节点。

### 分支线：燃烧的归途（毁船）

霍尔保留的砷化氢罐让“验证”变成攻击方案。他们用弃置器材作为诱饵，把气体送入船闸；假船表面开始融化，却仍保持飞船轮廓。为了不让其逃离，必须有人在近处触发点火或切断着陆场供能。玩家可让霍尔承担，或说服受伤卫兵远程完成；两种变体都付出明确代价。真船抵达后只能在空中接收幸存者信号，着陆场已被有毒燃烧物覆盖。一个月后，蓝星进入军事封锁；行动被记录为“成功销毁未知载体”，而复制生态是否只存在这一处仍无人敢下结论。

- 独有场景：着陆场维护沟、燃烧后隔离线。
- 后果：假船毁灭；有人牺牲或重伤；地表污染；军事封锁。
- 预算：16–20节点。

### 隐藏线：无物之地（永久隔离）

霍尔集齐全部证据后作出更彻底判断：真船也无法仅凭外观被证明是真。全员拒绝靠近任何飞船，用基地的有机标记和远距语音要求戴维斯不要着陆。戴维斯在轨道保持通讯，地面人员拆除可疑设施，转移到裸露湖岸。三天后补给仍不能投放；一个月后，蓝星被永久列为禁止接触区，幸存者成为自愿留下的隔离群体。他们建立一套不依赖所有权和物件的生活纪律。最后，霍尔看见湖面映出两个太阳般的亮点，却不再走近确认。

- 独有场景：湖岸临时营地、轨道通讯夜班。
- 后果：全员活着但无法回地球；殖民永久取消；制度把他们记为隔离人员而非英雄；基地物件被弃置。
- 预算：20–26节点。

## 四、草率结局线

### R1《检测合格》

霍尔接受心理测试结论，不再追查显微镜。殖民会议恢复，物资船提前开放。三天后重复器材遍布仓库，一个月后第一艘殖民船带着复制物离开蓝星。霍尔被安排回地球治疗，却在舷窗里看见两艘完全相同的补给艇。8–10节点。

### R2《第二只手套》

霍尔亲自戴上现场手套验证真假。手套先模拟贴合，再锁住腕部；救援人员因无法区分另一只而延误。通讯记录把死亡归为鲁莽实验，关键物证则在密封袋里恢复成普通手套。8–10节点。

### R3《无火花规定》

砷化氢实验中开枪，气体爆燃。实验室隔离门封死，莫里森只能从观察窗看见器材与人影一起融入热浪。基地失去唯一可用的显形测试，幸存者被迫在未知物件中等待救援。8–10节点。
