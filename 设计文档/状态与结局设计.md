# 状态与结局设计：《殖民地》

## 一、主状态值

- `variableName`：**误差**
- `initialVariable`：38
- 高值含义：不断比较、复核、寻找完美表面中的差异；代价是行动迟缓、难以再把任何对象当作安全前提。
- 低值含义：服从检测结果、程序和共同判断，能快速组织行动；代价是会把“符合规格”误当成“真实”。
- 关键阈值：25（程序优先）、50（主动复核）、70（任何保证都需第二证据）。
- 用途：改变霍尔观察细节、莫里森的措辞和部分调查选项；不单独决定任何正式结局。

## 二、自定义变量

| 变量 | 初始值 | 赋值位置 | condition用途 |
|---|---|---|---|
| `morrison_stance` | `formal` | 地毯救援与毒气实验后设为`aligned`或`guarded` | 决定她是否允许霍尔延迟撤离、是否公开支持 |
| `evacuation_order` | `board` | 终局决定设为`wait`、`burn`、`quarantine` | 第六章路径与结局路由 |
| `hall_condition` | `fit` | 受伤路径设为`injured` | 影响毁船线执行者与结局描写 |

不使用累加型自定义数值，避免与播放器仅支持`set`直接赋值冲突。

## 四、正式结局矩阵

| ID | 类型 | 标题 | 主要条件 | 内容方向 |
|---|---|---|---|---|
| `ending_original` | TRUE ENDING | 比人更大的仿制品 | `evacuation_order == 'board'`或默认兜底 | 全员进入假船；真戴维斯按时抵达 |
| `ending_partial` | BRANCH ENDING | 留在地面的人 | `committed_wait`，但未凑齐救全员证据；`held_morrison_back` | 霍尔与莫里森留下，其他人失踪 |
| `ending_rescue` | NORMAL ENDING | 按时抵达 | `committed_wait` + `noticed_clock` + `noticed_silence` + `verified_call_sign` | 全员后撤，等到真船并按协议撤离 |
| `ending_burn` | BRANCH ENDING | 燃烧的归途 | `committed_burn` + `kept_arsine_reserve` | 毁掉假船并付出牺牲/污染代价 |
| `ending_quarantine` | HIDDEN ENDING | 无物之地 | `committed_quarantine` + `noticed_clock` + `noticed_silence` + `checked_hull` + `checked_dark_airlock` + `heard_davis_eta` | 拒绝真假两船，永久留在蓝星隔离 |

最终route顺序：quarantine → burn → rescue → partial → original(default)。

## 五、非原作结局六问推演

### `ending_partial`

1. 改变谁：霍尔、莫里森生还；其他队员死亡。
2. 三天后：两人在真船隔离舱逐帧复盘假船出现。
3. 一个月后：军事调查将事故列为判断与指挥失败。
4. 关系：两人互相证明对方没有发疯，也互相承担没有拦住众人的责任。
5. 制度：殖民冻结但蓝星未被永久封锁；时钟成为核心证物。
6. 主题：看见误差只能救下愿意停步的人。

### `ending_rescue`

1. 改变谁：全体幸存者与戴维斯船员都免于假船吞噬。
2. 三天后：所有人处于分舱隔离，禁止接触个人物品。
3. 一个月后：地球冻结殖民计划，成立无机拟态隔离标准。
4. 关系：莫里森公开承认霍尔的复核挽救全队；弗兰德利不再拿“多疑”开玩笑。
5. 制度/物件：基地时钟和通讯记录被封存；蓝星列为一级危险。
6. 主题：世界没有变得可辨认，人类只是第一次承认了判断的限度。

### `ending_burn`

1. 改变谁：多数队员获救，近距离执行者死亡或重伤。
2. 三天后：真船在轨等待，地面人员绕开有毒着陆场。
3. 一个月后：军方把蓝星变成封锁区，并研究燃烧残留物。
4. 关系：幸存者对牺牲者的判断既感激又无法确认是否必要。
5. 制度/物件：备用砷化氢罐熔毁；假船残骸成为永远无法安全打捞的证物。
6. 主题：摧毁一个完美复制品不等于证明周围其余东西真实。

### `ending_quarantine`

1. 改变谁：全队存活但失去返乡资格；戴维斯避免接触风险。
2. 三天后：队员迁到湖岸，抛弃基地大部分设施。
3. 一个月后：地球宣布蓝星永久禁入，幸存者被列为隔离居民。
4. 关系：军衔秩序逐渐让位于共享观察和轮值；霍尔与莫里森不再讨论“救援”。
5. 制度/物件：所有基地物件留在封锁线内；轨道只传递信息，不投送物资。
6. 主题：当真实性无法证明，最彻底的保护是拒绝把未知带回人类世界。

## 八、三类玩家路径测试

- 直觉玩家：追随命令、不过度观察 → `ending_original`；完整而非惩罚性短结局。
- 谨慎玩家：至少注意时钟并要求等待 → `ending_partial`；若继续验证静默和呼号 → `ending_rescue`。
- 探索玩家：复核物证、保留砷化氢或集齐全部船体线索 → `ending_burn`或`ending_quarantine`。
- 所有正式终局路由均有`default`指向`ending_original`，不会死锁。
