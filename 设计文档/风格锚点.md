# 风格锚点：《殖民地》

## 叙述温度

基础温度为明亮环境下的冷叙述，靠日常物件执行精确的物理动作制造恐怖，而不是靠阴影、怪叫或情绪形容词。

- 日常与实验：中等句长，技术名词和干冷玩笑并置。
- 微异常：句子缩短，每屏只增加一个可观察事实。
- 活化袭击：短句、动词密集、动作清楚，不解释感受。
- 真相显露：恢复实验报告般的冷静，把荒诞当作可测量事实。
- 结局：不复述过程，以一个物理事实和一句短判词收束。

## 对白规则

- 通用：高度口语化；军官仍保持职业措辞。压力越高，句子越短。
- 霍尔：先给观察或结论，再说明证据；不发表英雄宣言。
- 莫里森：命令式、陈述式；证据不足时强调纪律，证据出现后迅速转向行动。
- 弗兰德利：调侃和常识判断较多，用玩笑抵挡不适。
- 戴维斯：礼貌而克制，对荒诞请求只追问操作细节。
- 选项中的对白直接写引号内台词，不用“说、问、声明”等概括词。

## 节奏规则

- 结构节拍：日常铺陈 → 一个微异常 → 物件活化 → 短暂恢复秩序。
- 平静节点每屏2–4句；追逐或搏斗节点每屏1–2句。
- 首次袭击、砷化氢显形、假船舱门三处不插入解释性长选项。
- 选择放在“观察到事实之后、采取行动之前”。
- 重复场景采用变奏：第二次出现同类物件时，更快、更具体，不照抄第一次。

## 视角转换

- 原作第三人称有限视角转为第二人称“你”，玩家扮演劳伦斯·霍尔。
- 只写霍尔能够看到、听到、闻到和通过专业知识判断的内容。
- 原作中其他角色单独遇害的片段，改为通讯、录像残片、现场遗留物或搜救报告，避免跳成全知视角。
- 不写“你意识到”“你感到恐惧”；改写为可观察行为，例如手指停在开关上、第二次核对时间。
- 真结局允许最后一个极短节点切到戴维斯视角，完成原作的信息差收束。

## 禁止清单

- 不把复制物设计成有牙齿、眼睛、触手或叫声的传统怪物。
- 不解释其母体、文明、语言或阴谋；原作只提供生物学推测。
- 不用血红警报、霓虹紫、黑暗暴雨等替代实际的物理恐怖。
- 不靠角色长篇独白解释主题。
- 不用“勇气”“理智”“信任”这类通用主状态名。
- 不让玩家因一个无依据的幸运选项直接识破假船。
- 不把裸体撤离写成低俗笑料；保留原作的干冷荒诞和人的脆弱感。

## 视觉锚点

- 核心句：**正常光线下，完美表面出现一毫米错误。**
- 色板：军用白 `#E4E6E2`、冷灰 `#9AA19C`、缝隙灰 `#525A58`、蓝星深绿 `#365F3F`、叶面绿 `#7DAA5A`、天空蓝 `#8EBBD4`、融解乳白 `#E8E0CF`、淡琥珀 `#CDBB91`。
- 基地材质：哑光喷涂金属、密封胶条、磨损标签、轻微积灰。
- 复制物完美态：无指纹、无孔隙、反光过度均匀，比原件饱和度高约4%。
- 显形态：半透明明胶质感、内部微粒、缓慢拉丝；无血液和器官。
- 构图：框中框、重复物、破坏一处的对称；给游戏 UI 保留干净负空间。
- 光线：始终自然、正常；恐怖来自材质变化，不来自灯光突变。
